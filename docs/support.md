# Support

*[Polski](#pomoc)*

**Problems or ideas?** Open an issue at [github.com/jakgajtk/biegocz/issues](https://github.com/jakgajtk/biegocz/issues).

**Backing up your data.** Everything is stored only on your iPhone. Use Settings → Export data to save a JSON file (plus a CSV of all gym sets) to Files or anywhere else, and Settings → Import data to restore it.

**Importing from Strava.** On strava.com, go to Settings → My Account → Download or Delete Your Account and request your archive. Unzip it (the Files app can do it), then in Biegocz choose Settings → Import from Strava or MapMyRun and pick the folder. Activities you already have are skipped.

**Route not recorded with the screen locked.** Check that location access for Biegocz is set to "While Using the App" in Settings → Privacy & Security → Location Services, and that Low Power Mode is off.

**Workouts don't appear in Apple Health.** Open Settings → Health → Data Access & Devices → Biegocz and turn on the categories you want to share.

# Pomoc

**Problem lub pomysł?** Zgłoś go na [github.com/jakgajtk/biegocz/issues](https://github.com/jakgajtk/biegocz/issues).

**Kopia zapasowa.** Wszystkie dane są tylko na Twoim iPhonie. Opcją Ustawienia → Eksportuj dane zapiszesz plik JSON (oraz CSV ze wszystkimi seriami) w Plikach lub gdziekolwiek indziej, a opcją Ustawienia → Importuj dane przywrócisz dane.

**Import ze Stravy.** Na strava.com wejdź w Ustawienia → Moje konto → Pobierz lub usuń konto i poproś o archiwum. Rozpakuj je (np. w aplikacji Pliki), a potem w Biegoczu wybierz Ustawienia → Importuj ze Stravy lub MapMyRun i wskaż folder. Aktywności, które już masz, zostaną pominięte.

**Trasa nie nagrywa się przy zablokowanym ekranie.** Sprawdź, czy dostęp do lokalizacji dla Biegocza jest ustawiony na „Podczas używania aplikacji” w Ustawieniach → Prywatność i ochrona → Usługi lokalizacji oraz czy tryb niskiego zużycia energii jest wyłączony.

**Treningi nie pojawiają się w Zdrowiu.** Otwórz Ustawienia → Zdrowie → Dostęp do danych i urządzenia → Biegocz i włącz kategorie, które chcesz udostępniać.
